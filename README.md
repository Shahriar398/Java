# 🍽️ Restaurant Management System

A Java-based Restaurant Management System developed to manage restaurant operations efficiently. The system provides functionalities for handling customer information, menu management, orders, and basic record keeping.

## 📖 Overview

This project was developed as an academic software project to demonstrate Object-Oriented Programming (OOP) concepts and Java application development. The system helps automate common restaurant management tasks and provides a simple interface for managing restaurant data.

---

## ✨ Features

- Customer information management
- Food menu management
- Order processing
- Bill generation
- Data storage using text files
- User-friendly interface
- Object-Oriented Design

---

## 🛠️ Technologies Used

- Object-Oriented Programming (OOP)

- Java Classes and Objects

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Shahriar398/Restaurant-Management-System.git
```

2. Open the project in your preferred Java IDE (IntelliJ IDEA, Eclipse, or NetBeans).

3. Compile and run:

```bash
javac Run.java
java Run
```
